# GreenMind 前端交付说明

**版本**: v1.0 | **日期**: 2026-11-15 | **负责人**: A（前端）
**基准**: 《GreenMind 开发规格书（执行版）》（3 人 × 10 周）；流程产物见 `specs/001–009` 与 `.specify/memory/constitution.md`。

前端 9 个页面（001–009）已全部完成，默认**演示数据模式**可独立端到端运行，无需后端。本文档覆盖启动、演示账号、逐模块切换、各页验收与后端联调。

## 1. 技术栈（宪法锁定）

Vue 3 + Vite + TypeScript + Element Plus + ECharts 5 + Pinia + Vue Router + axios + markdown-it + html5-qrcode；签名用原生 canvas。无清单外运行时依赖。

## 2. 环境要求

- Node.js ≥ 18（实测 v22）、npm ≥ 9
- 现代浏览器（Chrome / Edge 最新两个大版本）；巡检页适配移动端

## 3. 快速启动

```bash
cd frontend
npm install            # 安装依赖（含 package-lock.json，可复现）
npm run dev            # 开发服务器 → http://localhost:5173（默认演示模式）
```

生产构建与预览：

```bash
npm run build          # vue-tsc 类型检查 + vite build（须一次通过）
npm run preview        # 预览构建产物 → http://localhost:4173
```

> dev 服务器已配置代理：`/api` 与 `/uploads` → `http://localhost:8000`（后端）。演示模式下不依赖该代理。

## 5. 演示模式与逐模块切换

| 变量 | 默认 | 说明 |
|---|---|---|
| `VITE_USE_MOCK` | `true`（`.env.development`） | 全局演示数据开关 |
| `VITE_REAL_MODULES` | 空 | 逗号分隔、强制走真实接口的模块名，覆盖全局 mock |

**模块名清单**（与 `src/api/*.ts` 一一对应）：
`auth`、`data`、`alarm`、`prediction`、`workorder`、`device`、`inspection`、`report`、`assistant`、`user`

**切换规则**：`VITE_USE_MOCK=false` → 全部真实；`true` 时，列入 `VITE_REAL_MODULES` 的模块走真实，其余仍 mock，互不影响。

**示例**（后端先交付登录与数据接口时）：

```bash
# frontend/.env.development 或启动环境变量
VITE_USE_MOCK=true
VITE_REAL_MODULES=auth,data
```

后端每交付一个模块，就把对应模块名追加进 `VITE_REAL_MODULES`，无需改业务代码。mock 数据结构与后端 Swagger 契约一致（见各 feature `contracts/`）；不一致时**以 Swagger 为准修正 mock**，不改页面适配错误结构。

## 8. 统一接口约定（摘要）

详见 [`docs/前后端开发约定.md`](./前后端开发约定.md)。要点：路由前缀 `/api`；JWT HS256 24h、`Authorization: Bearer`；
分页 `{items,total,page,page_size}`（page_size≤100）；错误 `{"detail"}` + 400/401/403/404；时间 ISO 8601；
SSE 事件名 `alarm/token/done`；上传 ≤5MB 仅 jpg/png；三角色权限前端隐藏 + 后端 `require_role` 双层。

## 12. 已知限制（演示模式）

- **PDF 导出**：mock 模式打开打印预览窗口，由浏览器"另存为 PDF"；真实模式直接下载后端 xhtml2pdf 生成的 PDF。Excel 导出 mock 生成可打开的 `.xls`。
- **真实 SSE 鉴权**：`EventSource` 无法自定义请求头，真实模式告警/助手流的 token 传递需后端支持查询参数或 cookie（联调时确认）。
- **扫码**：桌面/无相机环境自动降级为手动选设备；移动端需 HTTPS 或 localhost 才能调用相机。
- 演示数据为样例，不代表现场事实；超标为运维提示，非监管合规判定。
